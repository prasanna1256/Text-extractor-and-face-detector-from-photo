Text extractor and face detector

a python website to analyze photos
1. it checks for no.of persons available in a photo and draws circle around their head
2. It returns the text in the photo
this is developed using Python(Streamlit,OpenCV,Numpy,matplotlib, pytesseract,dlib,etc.medianBlur photo preprocessing,)

the photo is converted into gray scale from increasing accuracy and based on the quality of the picture, the accuracy varies.
