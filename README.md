Text extractor and face detector

a python website to analyze photos
1. it checks, no.of persons available in a photo and draws circle around their head
2. It returns the text available in the picture that you've uploaded.
this is developed using Python(Streamlit,OpenCV,Numpy,matplotlib, pytesseract,dlib,etc.medianBlur photo preprocessing,).

the photo is converted into gray scale for increasing accuracy, managing pixel rate,contrast,brightness of a photo.
Based on the quality of the picture, the accuracy varies, good quality picture gives accurate data.
